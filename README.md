# Triplan
여행 성향 기반 SNS &amp; AI 일정 추천 앱

🛠 기술 스택

React Native (CLI)
Node.js / Express
PostgreSQL
Google Gemini API
Google Maps API / Kakao Map API
WebSocket (Socket.io)


🚀 시작하기
bashgit clone https://github.com/HSU-Triplan/Triplan.git
cd Triplan
npm install
npx react-native run-android

📂 프로젝트 구조
src/
├── pages/         # 화면 컴포넌트
└── navigation/    # 탭 네비게이터
